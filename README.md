# 🧠 Swarm Intelligence Based Biomedical Image Denoising

## 📌 Overview
A biomedical image denoising project using **Particle Swarm Optimization (PSO)** to reduce noise while preserving important anatomical structures in MRI and CT images.

## 🎯 Key Features
- Adaptive 3×3 convolution filter optimization using PSO.
- SSIM-based fitness evaluation.
- Image enhancement using Unsharp Masking.
- Tested on BraTS (MRI) and LUNA16 (CT) datasets.
- Performance evaluation using PSNR, SSIM, SNR, and CNR.

## ⚙️ Methodology
1. Biomedical image preprocessing.
2. PSO swarm initialization.
3. Fitness evaluation using SSIM.
4. Optimization of filter coefficients.
5. Image denoising and enhancement.
6. Performance evaluation.

## 📊 Results

| Dataset | PSNR Improvement |
|---|---:|
| BraTS (T1) | +3.36 dB |
| BraTS (T2) | +2.65 dB |
| LUNA16 | +2.75 dB |
